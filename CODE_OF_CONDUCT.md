# Code of Conduct

This project values direct communication, careful reasoning, and evidence that other contributors can inspect.

## Expected behavior

- Discuss the proposal, evidence, and repository impact.
- State uncertainty when the available information is incomplete.
- Keep feedback specific, respectful, and actionable.
- Make room for contributors with different levels of context.

## Unacceptable behavior

- Harassment, threats, discrimination, or personal attacks.
- Deliberate misrepresentation of test results, sources, or repository state.
- Publishing private information without permission.
- Disrupting project infrastructure or submitting intentionally unsafe changes.

Project maintainers may remove content, close discussions, or restrict participation when necessary to protect the project and its contributors. Concerns should be reported through the private path described in [`SECURITY.md`](SECURITY.md) when they contain sensitive information.
